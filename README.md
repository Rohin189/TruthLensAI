# TruthLens AI

Hallucination-aware RAG framework with LoRA fine-tuning, evidence-based
claim verification, trust scoring, and self-correction.

## Status
🚧 Phase 2 — environment & project scaffolding

## Stack
- LLM: Qwen2.5-7B-Instruct (LoRA fine-tuned)
- Embeddings: BAAI/bge-base-en-v1.5
- Vector DB: ChromaDB
- Backend: FastAPI | Frontend: Streamlit
- Eval: RAGAS, DeepEval
